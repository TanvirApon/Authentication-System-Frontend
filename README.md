# 🎨 Authentication System Frontend

A modern Authentication System frontend built using React.js and TypeScript.

This project includes secure authentication UI with Login, Register, JWT Authentication Flow, Refresh Token Handling, Protected Routes, Session Management, and modern responsive UI design.

---

## 🚀 Features

- Login & Register UI
- JWT Authentication Flow
- Refresh Token Support
- Protected Routes
- Persistent Authentication
- Session Management
- Axios API Integration
- Global State Management using Zustand
- Responsive UI Design
- Reusable Components
- Form Handling & Validation
- Clean Folder Structure
- Dark Modern UI

---

## 🔑 Authentication Flow

### 1️⃣ User Login

User logs in using email and password.

```json
{
  "email": "user@gmail.com",
  "password": "123456"
}
```

---

### 2️⃣ Backend Authentication

Frontend sends authentication request using Axios.

---

### 3️⃣ JWT Token Handling

After successful login:

- Access Token received
- Refresh Token handled securely
- User session initialized

---

### 4️⃣ Protected Routes

Unauthorized users cannot access protected pages.

---

### 5️⃣ Persistent Session

User stays logged in using refresh token authentication flow.

---

### 6️⃣ Logout

Logout clears authentication state and session data.
